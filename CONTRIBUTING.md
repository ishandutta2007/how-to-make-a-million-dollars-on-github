# Contributing to how-to-make-a-million-dollars-on-github

First off, thank you for considering contributing to this project! It's people like you that make the open-source community such an amazing place to learn, inspire, and create.

## How Can I Contribute?

### Reporting Bugs
* Check the [issue tracker](https://github.com/ishandutta2007/how-to-make-a-million-dollars-on-github/issues) to see if the bug has already been reported.
* If you can't find an open issue that addresses the problem, [open a new one](https://github.com/ishandutta2007/how-to-make-a-million-dollars-on-github/issues/new). Be sure to include a title and clear description, as much relevant information as possible, and a code sample or an executable test case demonstrating the expected behavior that is not occurring.

### Suggesting Enhancements
* Open a new issue and describe the enhancement you'd like to see.
* Explain why this enhancement would be useful to most users.

### Pull Requests
* Fill in the required template.
* Do not include more than one change per pull request.
* Ensure your code follows the existing style.

## Styleguide

* Keep the tone professional, inspiring, and actionable.
* Use Markdown properly for readability.
* Ensure all links are working.

## Questions?

If you have any questions, feel free to open an issue for clarification.

Thanks again for your contributions!
